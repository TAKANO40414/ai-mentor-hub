# ジェネギャすきる

上司と部下をつなぐ社内サポートWEBアプリです。以下の4つの機能を持ちます。

1. **社内ナレッジAI**：会社のルールや技術情報を登録しておくと、部下が質問した際にキーワードマッチングで回答します。
2. **共有チーム予定表**：上司・部下全員の予定を月・週・日の3表示で人ごとの色分けで確認できます。抽出（表示する人の絞り込み）・再読み込み・本日ハイライトに対応。各自は自分の予定を追加でき、部下は上司へアポイントを申請できます（上司が承認/却下）。
3. **マニュアル**：ルール・技術要点・お知らせをカテゴリ別に上司が登録し、部下がいつでも確認できます。テキスト入力に加えて、PDFファイルをアップロードして登録することもできます。
4. **上司⇔部下チャット**：1対1で直接やり取りできるチャット機能。
5. **AI要約（上司専用）**：文書のテキストやPDFをClaude APIに送り、図解（Mermaid図）付きの要約ドキュメントに変換します。変換結果は「技術伝承に入れる」でAIが手順に分け、技術伝承タブの球体に点（コツ）として入れられます。
6. **全体お知らせ**：上司がダッシュボードから入力すると、ログイン画面にポップアップとして表示されます。
7. **AIチャット**：Claude APIとの自由な会話ができるチャット機能（上司・部下どちらも利用可能）。会話は保存されず、ページを離れるとリセットされます。会話ごとに使用するモデル（Claude Sonnet 5 / Opus 5 / Haiku 4.5 / Fable 5、およびローカルOllamaのモデル）をドロップダウンで選択できます。
8. **音くらべ検品（AIタブ内）**：基準音声（正常品）と検査音声を比較し、差分ヒートマップ・差スコアとしきい値で **正常 OK / 異常 NG** を判定するブラウザ完結型の検品ツール（[otokurabe-kenpin](https://github.com/TAKANO40414/otokurabe-kenpin) を統合）。マイク録音・ファイル読み込みに対応し、正常品リストはブラウザ（IndexedDB）に保存されます。音声は外部に送信されません。マイク録音はhttpsまたはlocalhostでのみ使用できます。
9. **技術伝承「球体を回す」**：ベテランの暗黙知を 点（コツ）・線（手順）・円（工程）・球（関係）として記録し、球体を指で回して「裏側（まだ見えていない部分）」を見るアプリ。一人称カメラ動画・音声メモ・文字起こしの記録、視点カードによる引き出し、工程・手順の整理、「この症状のとき、ベテランはどこを見る？」と聞けるAIチャットの4機能を持ちます。記録はブラウザ（IndexedDB）に保存され、AIはサーバーの `ANTHROPIC_API_KEY` を使います（未設定時はキーワード検索で代替）。カメラ・マイクはhttpsまたはlocalhostでのみ使用できます。`public/sphere/` に単体アプリとして入っており、単独でも動きます。
10. **音声からマニュアル作成（AIタブ内）**：ベテランの語りを録音しながらブラウザで文字起こしし（Web Speech API。文字起こし済みテキストの貼り付け・読み込みも可）、Claudeが「手順・視点タグ（手元／目線／機械）・注意点・コツ・確認事項」の形のマニュアルに整理します。できたマニュアルは、上司なら「マニュアル（技術要点）」に登録でき、誰でも「技術伝承」タブの球体に工程（円）と点（コツ）として入れられます。 逆に、マニュアルタブに登録済みのテキスト／PDFマニュアルも、各カードの「技術伝承に入れる」から AI が手順に分けて球体に点として入れられます（AIが使えないときは本文を1つの点として入れます）。
11. **手書きをデータ化（AIタブ内）**：手書きのマニュアル・リスト・帳面を写真に撮ってアップロードすると（複数枚可、端末側で縮小してから送信）、Claudeが読み取って「表」または「マニュアル（手順）」にします。表は画面上でセルを直してから Excel（.xlsx）／CSV に保存でき、上司は「マニュアル（技術要点）」に登録、誰でも「技術伝承」タブの球体に点として入れられます（表は1行＝1点）。判読できなかった箇所は一覧で示します。Excel 書き出しは SheetJS を CDN から読み込むためインターネット接続が必要です（無い場合は CSV で保存できます）。

## 構成

- Node.js + Express によるバックエンド（`server/`）
- 素の HTML/CSS/JavaScript によるフロントエンド（`public/`）
- データは `data/db.json` に保存されるシンプルなファイルベースDB（デモ用）

## AI機能のセットアップ（任意）

「AI要約」（上司専用）と「AIチャット」（全員利用可）を使うには、[Anthropic Console](https://console.anthropic.com/) でAPIキーを取得し、プロジェクトルートに `.env` ファイルを作成してください（`.env.example` をコピーして編集できます）。

```bash
cp .env.example .env
```

```
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-5   # 省略可
```

APIキーを設定しない場合、他の機能は通常通り使えますが「AI要約」「AIチャット」タブでエラーメッセージが表示されます。「AI要約」はブラウザ側でMermaid/Marked（図解・Markdown描画用ライブラリ）をCDNから読み込むため、インターネット接続が必要です。

### ローカルOllamaを使う（任意）

APIキー不要でローカルのLLMを使いたい場合は、[Ollama](https://ollama.com/) をインストールして起動し、使いたいモデルを `ollama pull llama3` などで取得しておいてください。サーバー起動中にOllamaが `http://localhost:11434` で動いていれば、インストール済みモデルが自動でAIチャットの「ローカルOllama」グループに表示されます。Ollamaを別のホスト・ポートで動かす場合は `.env` の `OLLAMA_BASE_URL` を変更してください。

## 起動方法

### 1クリックで起動（Mac）

フォルダ内の **`起動.command`** をダブルクリックしてください。初回のみ依存パッケージのインストールが走り、その後サーバーが起動してブラウザが自動で開きます。終了する場合は開いたターミナルウィンドウを閉じてください。

### コマンドラインから起動

```bash
npm install
npm start
```

`http://localhost:3000` にアクセスしてください。

## Renderへのデプロイ（インターネット公開）

このリポジトリには `render.yaml` が含まれているため、[Render](https://render.com/) のBlueprint機能でGitHubから直接デプロイできます。

1. [Render](https://dashboard.render.com/) に登録し、GitHubアカウントを連携する
2. ダッシュボードで **New + → Blueprint** を選び、この `ai-mentor-hub` リポジトリを選択する
3. `render.yaml` の内容が自動検出されるので、`ANTHROPIC_API_KEY` の値を入力して「Apply」する（`SESSION_SECRET` は自動生成されます）
4. デプロイ完了後に発行されるURL（`https://xxxxx.onrender.com`）にアクセスする

**注意（無料プランの制約）**：Renderの無料プランはディスクが永続化されないため、`data/db.json`（予定・マニュアル・アナウンス・チャット履歴など）やアップロードしたPDFは、再デプロイやアプリの再起動（無料プランは15分間アクセスが無いと自動的にスリープします）のたびに初期状態（デモ用の3アカウントなど）にリセットされます。実運用でデータを保持したい場合は、有料プランの永続ディスクを追加するか、外部データベースへの移行が必要です。また、ローカルOllamaはRenderのサーバーからは利用できません（Claudeモデルのみ利用可能です）。

## メンテナンス画面（ユーザー管理）

ログイン画面の「ログイン先」で **メンテナンス画面** を選び、メンテナンス用アカウント（`mainte` / `mainte123`）でログインすると、ユーザー管理画面が開きます。ここでアプリを利用する人の **名前・役職・ID・パスワード** の追加・編集・削除ができます。メンテナンスアカウント自体はアプリ本体にはログインできず、ユーザー一覧にも表示されません。

役職は「役職管理」で自由に追加できます（例：課長・主任など）。各役職には権限（**上司相当**＝管理機能あり／**部下相当**＝一般）を紐づけ、ユーザーにはその役職を割り当てます。ユーザーに設定中の役職は削除できません。

## 注意事項

本アプリはデモ・プロトタイプとして、ファイルベースの簡易データストアとセッション認証を使用しています。実運用にはデータベースやHTTPS、パスワードポリシーなどの強化が必要です。

予定表は全員が全員の予定タイトルを見られる共有チームカレンダーです（以前のバージョンにあった「上司の予定は部下に詳細非公開」という制限は廃止しています）。予定の削除は本人のみ可能です。
