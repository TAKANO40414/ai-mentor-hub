# ジェネギャすきる

上司と部下をつなぐ社内サポートWEBアプリです。以下の4つの機能を持ちます。

1. **社内ナレッジAI**：会社のルールや技術情報を登録しておくと、部下が質問した際にキーワードマッチングで回答します。
2. **上司の予定確認＆アポ取得**：上司の本日の予定から「質問できる時間」をリアルタイムに表示し、部下は空き時間にアポイントを申請できます（上司が承認/却下）。
3. **マニュアル**：ルール・技術要点・お知らせをカテゴリ別に上司が登録し、部下がいつでも確認できます。テキスト入力に加えて、PDFファイルをアップロードして登録することもできます。
4. **上司⇔部下チャット**：1対1で直接やり取りできるチャット機能。
5. **AI要約（上司専用）**：文書のテキストやPDFをClaude APIに送り、図解（Mermaid図）付きの要約ドキュメントに変換します。
6. **全体お知らせ**：上司がダッシュボードから入力すると、ログイン画面にポップアップとして表示されます。

## 構成

- Node.js + Express によるバックエンド（`server/`）
- 素の HTML/CSS/JavaScript によるフロントエンド（`public/`）
- データは `data/db.json` に保存されるシンプルなファイルベースDB（デモ用）

## AI要約機能のセットアップ（任意）

「AI要約」タブ（上司専用）を使うには、[Anthropic Console](https://console.anthropic.com/) でAPIキーを取得し、プロジェクトルートに `.env` ファイルを作成してください（`.env.example` をコピーして編集できます）。

```bash
cp .env.example .env
```

```
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-5   # 省略可
```

APIキーを設定しない場合、他の機能は通常通り使えますが「AI要約」タブでエラーメッセージが表示されます。この機能はブラウザ側でMermaid/Marked（図解・Markdown描画用ライブラリ）をCDNから読み込むため、インターネット接続が必要です。

## 起動方法

### 1クリックで起動（Mac）

フォルダ内の **`起動.command`** をダブルクリックしてください。初回のみ依存パッケージのインストールが走り、その後サーバーが起動してブラウザが自動で開きます。終了する場合は開いたターミナルウィンドウを閉じてください。

### コマンドラインから起動

```bash
npm install
npm start
```

`http://localhost:3000` にアクセスしてください。

## 注意事項

本アプリはデモ・プロトタイプとして、ファイルベースの簡易データストアとセッション認証を使用しています。実運用にはデータベースやHTTPS、パスワードポリシーなどの強化が必要です。
